## func repository add

Add a repository

```
func repository add <name> <url>
```

### Options

```
  -c, --confirm[=true|false]   Prompt to confirm options interactively ($FUNC_CONFIRM)
  -h, --help[=true|false]      help for add
  -v, --verbose[=true|false]   Print verbose logs ($FUNC_VERBOSE)
```
